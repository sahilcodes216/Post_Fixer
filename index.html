All Algorithms & Rules

  • Operands: Single characters A–Z, a–z, and digits 0–9.
  • Operators: +, -, *, /, ^, (, ).
Algorithm for Infix to Postfix Conversion:
  1. Initialize an empty stack for operators. Add '(' into the stack and ')' to the infix expression.
  2. Initialize an empty list/array for the output (postfix expression).
  3. Start scanning the tokens/characters of the infix expression from left to right.
  4. For each token in the infix expression:
    1. If the token is an operand:- Append it to the output.
    2. If the token is an operator (op1):
      • While there is an operator (op2) at the top of the stack with greater precedence, or equal precedence and op1 is left-associative, then pop op2 from the stack and append it to the output.
      • Push op1 onto the stack.
    3. If the token is a left parenthesis '(': Push it onto the stack.
    4. If the token is a right parenthesis ')':
      • Pop operators from the stack and append to output until a left parenthesis is encountered.
      • Pop and discard the left parenthesis.
  5. Repeat step 3 and 4 until the stack becomes empty.
  6. Return the output list as the postfix expression.
Algorithm for Postfix Expression Evaluation
  1. Initialize an empty stack.
  2. Scan the postfix expression from left to right, one token at a time.
  3. For each token:
    • If it's an operand → push it onto the stack.
    • If it's an operator (+, -, *, /) →
      • Pop the top two values: operand2 = pop(), then operand1 = pop()
      • Compute: result = operand1 operator operand2
      • Push result back onto the stack.
  4. Repeat step 3 until all tokens are scanned.
  5. Return the final value left on the stack — this is the result.
Algorithm for Infix to Prefix Conversion:
  1. Reverse the given infix expression. Also swap every ( with ) and every ) with (.
  2. Convert the reversed expression into postfix, but for equal-precedence operators, push the new operator on top instead of popping the existing one first. (This keeps the operators in the right order once you reverse everything in step 3.)
  3. Reverse the resulting postfix expression. This gives the final prefix expression.
For Verification by Evaluating:
  1. #For Prefix Expression:
    • Scan the token from Right → Left
  2. #For Postfix Expression:
    • Scan the token from Left → Right
